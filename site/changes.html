The release record of the AI model era.

Changes and corrections

The record changes in three ways: new releases are added, an entry is corrected when we or a source got something wrong, and an entry is retracted when it should not have been on the record. All three are listed here, built from the published files. A corrected entry keeps a note on its card with the old value and the evidence. To report an error, open an issue.
