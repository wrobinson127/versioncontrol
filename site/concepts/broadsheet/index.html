    Four rules apply to every number

    Every score names its source

    Each benchmark score carries a tag. LAB means the lab reported the score. IND means an independent evaluator measured it. The tag links to the source.

    We record what a lab did not publish

    Each missing item is marked not disclosed. That mark means we looked. Where we have not checked yet, the record says not yet researched instead.

    We do not compare scores that are not comparable

    A change against the previous model appears only when both scores are on the same benchmark, the same version of it, and from the same kind of source.

    Benchmark versions are fixed

    Every benchmark label carries its version: GPQA Diamond, never "GPQA"; SWE-Bench Verified, never "SWE-Bench". A revised benchmark is a different test.
