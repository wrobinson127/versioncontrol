Methodology

Version Control is a public release record of AI models from twelve tracked AI labs. For each release we track when it shipped, how the public can use it, what it scored on independent evaluations, and whether the lab published a paper, a system card, a model card, and a usage policy.

Four rules apply to every number on this site.

1. Every score names its source

Each benchmark score carries a tag. LAB means the lab reported the score. IND means an independent evaluator measured it. The tag links to the source, and the record stores the source URL, the benchmark name and version, and the date we retrieved it. Every score on the site has one of these tags. Our checks reject any score that has no source, so an untagged number cannot get onto the site.

In the record today

2. We record what a lab did not publish

A release still gets a card when the lab publishes no system card, model card, usage policy, or paper. The card says so. Each missing item is marked not disclosed.

That mark means we looked. We checked the lab's own sites and found nothing. Where we have not checked yet, the card says not yet researched instead. The two look different on the page and mean different things. "Not disclosed" is a fact about the lab. "Not yet researched" is work we have not done. For these four items, only researched releases count toward a percentage.

For releases before July 2026, we looked in July 2026. A document the lab published after launch therefore still counts. A link on record means the document exists. We do not grade what it says.

Parameter counts work differently. They come from Epoch AI's data, and we have not checked the labs' pages for them. Where Epoch has no count, the card says no count on record, not "not disclosed". Parameter percentages divide by all releases and say so.

In the record today

3. We do not compare scores that are not comparable

A change against the previous model appears only when both scores are on the same benchmark, the same version of it, and from the same kind of source. If the previous model was scored but the pair does not match, the card says no comparable measurement. If the previous model was never scored, the card says nothing, because a missing score and a refused comparison are different things.

Every comparison between models is calculated once, before publishing, and the site displays that result. The site only counts and rounds what is in the published files, and works out how many days old the record is.

In the record today

4. Benchmark versions are fixed

Every benchmark label carries its version: GPQA Diamond, never "GPQA"; SWE-Bench Verified, never "SWE-Bench". A revised benchmark is a different test. We never draw a line, a delta, or a chart across two versions. Where a lab published its evaluation settings, they appear under the score as written.
