Every number has an origin.

The record pins two benchmarks. Each point is one model's score at its release date. A solid mark is an independent measurement; a hollow mark is the number the lab reported for its own model.

For the same model on the same benchmark, the lab's number and an independent evaluator's number are often different, in both directions. The record keeps both, with the configuration each was run under.
