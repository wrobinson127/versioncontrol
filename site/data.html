The dataset

The complete record is published as files. For a spreadsheet, use the two CSV files; for every source, the gzipped JSON, one file per year, indexed by the manifest. The same files drive this site. There is no separate API, and the paths below are stable.

Files

FileContents
releases.csvOne row per entry: dates, lab, availability, the four disclosure items, parameters, predecessor, and the primary source. Absence is written as a word (NOT_DISCLOSED or NOT_RESEARCHED), never left blank.
scores.csvOne row per benchmark score, with its source class, source URL, retrieval date and test settings.
manifest.jsonIndex of entry files with per-file entry counts, ids, and SHA-256 checksums.
derived/deltas.json.gzPredecessor comparisons per entry: a change, or the reason no change is shown. The site renders this file verbatim.
derived/views.json.gzDerived chart datasets: release cadence, benchmark trajectory series, disclosure matrix, and registry measures. The site's charts draw from this file and only count and round what is in it.
derived/site_meta.jsonRecord counts, date range, and the last successful update timestamp.

Fields

Each entry in the JSON files, and each row of releases.csv, carries these fields.

FieldMeaning
idStable identifier: organization key, two hyphens, model slug. It also opens the entry in the explorer: explorer.html?id=<id>.
model_name, orgThe model as the lab names it, and the organization key. A correction_note explains any name or date we corrected from the source.
dateThe release date: Epoch AI's date for entries built from its data (usually the announcement or paper date), and the lab's announcement date for entries found by the nightly check or recorded by hand. The methodology explains the exceptions.
entry_typerelease, or revision: an update to a model already on record, shipped under the same name.
availability_classopen_weights, public_api, or public_service (a product people can sign up for).
originHow the entry reached the record: backfill-epoch (from Epoch AI's dataset), nightly-pipeline (found by nightly detection, approved by hand), or manual (recorded by hand).
parametersTotal parameter count. NOT_DISCLOSED here means Epoch AI's dataset has no count; we have not checked the labs' pages. parameters_basis says whether a count is the lab's own or reported by others.
parameters_basislab (the lab's own count), third_party (a count Epoch AI records from a report by others: a rumor, a leak, an estimate, a newsletter, another party's paper or a post on X), or NOT_DISCLOSED when there is no count. Third-party counts are left out of every parameter finding.
parameters_noteJSON only, on third_party counts: Epoch AI's note on where the count came from.
predecessorThe id of the model this one follows, where the lab or the model family makes it clear. Comparisons against the predecessor are in derived/deltas.json.gz.
system_card, model_card, usage_policy, paperA link to the document, NOT_DISCLOSED (we checked the lab's pages and found none), or NOT_RESEARCHED (not yet checked). Neither means zero.
benchmarksScores on GPQA Diamond and SWE-bench Verified only. Each carries its source class (LAB_REPORTED or INDEPENDENT), source URL, benchmark version, retrieval date and test settings. scores.csv has one row per score.
sourcesEvery page the entry was built from, each with the date we read it.
retractedtrue when the entry should not have been on the record; the note says why. A corrected entry stays false and carries a correction_note instead.

Required attribution for Epoch AI derived fields

Portions of the dataset are derived from two Epoch AI datasets, both used under CC-BY 4.0. If you redistribute or build on those fields, you must retain the following attributions:

Epoch AI, "Data on AI Models". Published online at epoch.ai. Retrieved from https://epoch.ai/data/ai-models [online resource].
Epoch AI, "Capabilities & benchmarking". Published online at epoch.ai. Retrieved from https://epoch.ai/benchmarks [online resource].

Release dates, lab names, parameter counts and availability come from Epoch AI's models dataset. Independent scores come from Epoch AI's benchmarking data.

What the dataset does not contain

OpenRouter's catalog is not in the dataset, and the site does not show its prices or context lengths. Prices quoted in an entry's summary are the lab's own figures. Artificial Analysis data is not in the dataset either: we use it only for an internal check of which models we might be missing.

Cost of operation

The registry runs on static hosting and scheduled jobs at zero infrastructure cost, plus a small metered LLM cost for the nightly drafting step.
