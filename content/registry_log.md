# Registry change log

The registry is the closed set of organizations whose releases this project records (ruling D2). It is append-only; every change to it is logged here with a date and a reason. An organization enters the registry when it ships a model meeting Epoch AI's notability bar or sustains top-tier leaderboard presence.
